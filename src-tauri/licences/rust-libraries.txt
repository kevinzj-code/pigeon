The Rust libraries Pigeon links, and the notices that ask to travel with it.

This is not the whole dependency tree — Cargo.lock is that — but it is the set
whose licences require their text to be carried, plus the two that make the
HTTPS Pigeon uses to fetch a model on first run.

ring and the BoringSSL code it derives from carry three notices of their own;
they are in ring-and-BoringSSL.txt beside this file. The Apache 2.0 text that
several of these point at is reproduced in Qwen-Apache-2.0.txt, also beside
this file.
